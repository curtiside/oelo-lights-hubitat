Oelo Lights Hubitat Integration

Complete Configuration and Usage Guide

Key Features

  • Multi-Zone Control: Control up to 6 independent zones (requires separate virtual device per zone)
  • Pattern Capture: Capture patterns created/edited in the Oelo app and save them for future use (up to 200 patterns)
  • Pattern Types: Support for spotlight plans and non-spotlight plans with automatic type detection
  • Simple Commands: Easy-to-use commands for setting patterns and turning lights on/off
  • Auto-Polling: Automatic status polling with configurable intervals
  • No Authentication Required: Simple HTTP API with no credentials needed

⚠️ CRITICAL: Setup Steps Required Before Use

Before you can use any commands (On, Off, Apply Pattern, etc.), you MUST complete these steps in order:

  1. Configure Controller IP Address - Run the Scan for Controller command OR manually enter the Controller IP Address in device preferences, then save. Without this, the device cannot interact with the controller.
  2. Set a pattern in the Oelo Evolution app - Create or select a pattern in the Oelo Evolution app and apply it to your zone
  3. Run the Get Pattern command - In Hubitat, open your device and run the Get Pattern command to capture the pattern
  4. Refresh the Hubitat page - Refresh your browser page to see the captured pattern appear in the preferences

Without completing these steps first, commands will not work properly.

Installation

Method 1: Hubitat Package Manager (HPM) - Recommended

Open Hubitat Package Manager

  1. Ensure Hubitat Package Manager is installed on your hub
  2. Open HPM and select "Install"
  3. Search for "Oelo Lights"

    Fast search for Oelo in Hubitat Package Manager

  4. Select "Oelo Lights by curtiside"

    Select Oelo Lights by curtiside

  5. Follow the prompts to complete installation

Method 2: Manual Installation

  1. Open your Hubitat web interface
  2. Navigate to Drivers Code in the menu
  3. Click + New Driver
  4. Click Import and paste this URL: 
    https://raw.githubusercontent.com/curtiside/oelo-lights-hubitat/main/drivers/oelo-lights-zone.groovy
  5. Click Import and then Save

Configuration

⚠️ CRITICAL: Controller IP Address Must Be Configured First

Before the device can interact with your Oelo controller, you MUST configure the Controller IP Address:

  1. Run the Scan for Controller command to automatically discover the IP, OR
  2. Manually enter the Controller IP Address in device preferences
  3. Save the preferences - This is required for the device to connect to the controller

Without configuring and saving the Controller IP Address, the device cannot communicate with the controller and commands will fail.

Creating a Virtual Device

  1. Navigate to Hubitat → Devices → Add Virtual Device

    Add Virtual Device in Hubitat

  2. Select "Oelo Lights Zone" driver

    Select Oelo Lights Zone driver

  3. Name your device

    Name the virtual device

Required Settings

1. Controller IP Address (Required)

  • IP address of the Oelo controller on your local network
  • Format: IPv4 address (e.g., 192.168.1.100)
  • Automatically set when discovered via Scan for Controller command, or can be manually entered
  • Driver validates IP by attempting to connect to /getController endpoint

2. Zone Number (Required)

  • Zone number (1-6) that this driver instance controls
  • Each zone requires a separate virtual device instance
  • Range: 1-6

Optional Settings

Setting Default Description
Subnet to Scan Empty Subnet prefix for controller discovery (e.g., '192.168.1' or '10.16.1')
Poll Interval 300 seconds How often to poll controller status (Range: 10-3600 seconds)
Enable Auto Polling Enabled Automatically poll controller status
Patterns None Capture and manage up to 200 patterns
Spotlight Plan Lights Default list Comma-delimited list of LED indices for spotlight plans
Maximum LEDs per Zone 500 Maximum number of LEDs in this zone
Verify Commands Disabled Verify commands by checking controller status after sending
Command Timeout 10 seconds HTTP request timeout (Range: 5-30 seconds)
Enable Debug Logging Disabled Enable detailed logging for troubleshooting
Note: No credentials or authentication are required. The Oelo Lights controller uses an open HTTP API with no authentication.

⚠️ IMPORTANT: Refresh Required After Changes

Simply reload/refresh the page (F5 or Cmd+R) to see updated preferences.

Finding Controller IP Address

Method 1: Controller Discovery (Recommended)

The driver includes a network scanning feature to discover Oelo controllers:

  1. Open device preferences
  2. Click the Scan for Controller button

    Scan for Controller command

  3. The driver will scan your network subnet
  4. When found, the controller IP address is automatically set in the preferences
  5. Save the preferences - This is required for the device to connect to the controller
  6. The discovered IP address will be logged in the device logs and shown in the Controller IP Address preference description
Important: After running Scan for Controller or manually entering the IP address, you must save the preferences for the device to connect to the controller. Without saving, the device cannot communicate with the controller.
How Network Scanning Works:
  • Scans IP addresses in the configured subnet (e.g., 192.168.1.1-254)
  • Tests each IP with HTTP GET to /getController
  • Identifies Oelo controllers by checking for valid JSON response
  • When controller is found, IP address is automatically set in preferences

Method 2: Manual Methods

If automatic discovery doesn't work, you can manually find the IP address:

Oelo Evolution App:

  1. Open the Oelo Evolution app on your smartphone/tablet
  2. Navigate to Settings or Device Information
  3. Find the IP address listed there

Router Admin Interface:

  1. Log into your router's web interface
  2. Navigate to "Connected Devices" or "DHCP Client List"
  3. Look for device named "Oelo" or similar
  4. Note the IP address assigned

Network Scanner Tools:

Use network scanning software to scan your local network:

  • Fing (mobile app)
  • Angry IP Scanner (desktop)
  • nmap (command line): nmap -sn 192.168.1.0/24
  • Advanced IP Scanner (Windows)

Look for devices responding on port 80 (HTTP) that return JSON from /getController

Usage

⚠️ CRITICAL: Complete Setup Steps First

You must complete these steps in order before using commands:

  1. Configure Controller IP Address - Run Scan for Controller OR manually enter IP in preferences, then save. Without this, the device cannot communicate with the controller.
  2. Set a pattern in the Oelo Evolution app and apply it to your zone
  3. Run the Get Pattern command in Hubitat to capture it
  4. Refresh your browser page to see the pattern in preferences

Only after completing these steps can you use On, Off, Apply Pattern, or other commands.

Available Commands

Available device commands

The driver provides the following commands:

  • On: Turn on lights using the last used pattern or selected pattern
  • Off: Turn off the lights
  • Apply Pattern: Apply pattern chosen from Pattern Selection dropdown
  • On and Apply Pattern: Turn on and apply pattern in one action (for rule engines - pattern must be captured first via Get Pattern, pattern name must match exactly)
  • Get Pattern: Capture the current pattern from the controller and save it
  • Refresh: Get current state from controller
  • Scan for Controller: Scan network to discover Oelo controller IP address
  • Stop Scan: Stop the controller discovery scan

Using Pattern Selection

  1. Select Pattern in Preferences:
    • Go to device preferences
    • Pattern Selection: Choose from your configured patterns
    • Save preferences
  2. Execute Command:
    • Use Apply Pattern command to apply selected pattern
    • Commands appear in device tile or can be called from automations

Patterns

⚠️ CRITICAL: Pattern Workflow

Complete these steps in order before using any commands:

  1. Configure Controller IP Address First: Run Scan for Controller OR manually enter Controller IP Address in preferences, then save. This must be done before capturing patterns.
  2. Set Pattern in Oelo Evolution App: Create or select a pattern in the Oelo Evolution app and apply it to your zone
  3. Capture in Hubitat: Use the Get Pattern command to capture the current pattern from the controller
  4. Refresh Browser Page: Refresh your Hubitat browser page to see the captured pattern appear in preferences
  5. Now You Can Use Commands: After refreshing, you can select the pattern and use commands like Apply Pattern, On, etc.

Capturing Patterns

Capture and save patterns created/edited in the Oelo app:

  1. Edit Pattern in Oelo App: Use the Oelo Evolution app to create or modify a pattern on your controller
  2. Set Pattern on Controller: Apply the pattern to your zone using the Oelo app
  3. Capture in Hubitat: Use the Get Pattern command to capture the current pattern from the controller
  4. Refresh Browser Page: Refresh your Hubitat browser page to see the pattern appear in preferences
  5. Pattern Saved: The pattern is automatically saved with a stable ID and an initial display name
  6. Use Saved Pattern: Select the captured pattern from Pattern Selection dropdown and use Apply Pattern command

Pattern Types

The driver supports two types of patterns:

  • Spotlight Plans: Patterns with specific LEDs turned on and all others off
    • Automatically detected when patternType=spotlight
    • Can be customized via Spotlight Plan Lights setting to control which LEDs are active
    • Uses colors from the original captured pattern for the specified LEDs
  • Non-Spotlight Plans: All other pattern types (march, stationary, river, chase, twinkle, split, fade, sprinkle, takeover, streak, bolt, custom, etc.)
    • Standard pattern types with various effects
    • Existing behavior unchanged

Pattern Management

  • Up to 200 patterns can be stored per device
  • Duplicate Prevention: Patterns with identical parameters are automatically treated as the same pattern
  • Rename Patterns: Use Select Pattern to Rename dropdown and New Pattern Name text field in device preferences, then save. Remember to refresh your browser page after saving to see the renamed pattern.

    Renaming a captured pattern

  • Delete Patterns: Use the Delete Pattern dropdown in device preferences, then save. Refresh your browser page to see the updated pattern list.
  • Patterns appear in Pattern Selection dropdown for easy selection
  • Pattern ID is displayed in parentheses next to pattern name in dropdowns
Remember: After capturing, renaming, or deleting patterns, always refresh your Hubitat browser page to see the changes in the preferences tab.

Spotlight Plan Customization

Note: The Oelo controller only returns 40 lights from the getController command. As a result, spotlight plans are not fully represented in the response. To counter this limitation, the Spotlight Plan Lights can be set with a list of the lights that should be turned on.

For spotlight plans, you can customize which LEDs are active:

  1. Capture Spotlight Plan: Use Get Pattern to capture a spotlight pattern from the controller
  2. Configure Spotlight Plan Lights: In device preferences, set Spotlight Plan Lights to a comma-delimited list of LED indices (1-based, e.g., "1,2,3,4,8,9,10,11")
    • The setting is automatically normalized (duplicates removed, sorted, invalid indices skipped)
    • Current normalized value is displayed in the preference description
    • Default value includes common spotlight LED positions
  3. Automatic Modification: When you use a spotlight plan, only the LEDs specified in Spotlight Plan Lights will be turned on, using the colors from the original captured pattern
  4. Setting Changes: If you change Spotlight Plan Lights, all saved spotlight plans are automatically updated to use the new LED list

Example Automations

Example 1: Turn on pattern at sunset

  1. Create/edit pattern in Oelo Evolution app and apply it to the zone
  2. In Hubitat, use Get Pattern command to capture the pattern
  3. Create Rule Machine rule
  4. Trigger: Sunset
  5. Action: Call Apply Pattern command (after selecting the captured pattern in preferences)

Example 2: Turn off lights at midnight

  1. Create Rule Machine rule
  2. Trigger: Time (12:00 AM)
  3. Action: Call Off command

Example 3: Capture and reuse a favorite pattern

  1. Set up your favorite pattern in the Oelo app
  2. Use Get Pattern command in Hubitat to save it
  3. The pattern is now available in the Pattern Selection dropdown for use in automations

Example 4: Turn on and apply pattern in Rule Machine

Important: Pattern must be captured first using Get Pattern command. Pattern name must match exactly (case-sensitive) the saved pattern name.
  1. In Rule Machine, add action: "Run Custom Action"
  2. Select your Oelo device
  3. Choose On and Apply Pattern command
  4. Enter pattern name in the parameter field (e.g., "Christmas March") - must match saved pattern name exactly
  5. The device will turn on and apply the specified pattern

Troubleshooting

"Controller IP address not configured"

⚠️ CRITICAL: This Must Be Done First

Solution: The Controller IP Address must be configured before the device can interact with the controller:

  1. Run the Scan for Controller command to automatically discover the IP, OR
  2. Manually enter the Controller IP Address in device preferences → Controller Settings
  3. Save the preferences - This is required for the device to connect

Without configuring and saving the Controller IP Address, no commands will work.

"Invalid zone number"

Solution: Zone number must be 1-6

"Cannot connect to controller"

Possible causes:

  • Incorrect IP address
  • Controller is offline
  • Network connectivity issues
  • Firewall blocking connection
  • Controller on different network/VLAN

Solutions:

  • Verify IP address is correct
  • Ping controller: ping Controller_IP_Address
  • Check controller is powered on
  • Verify Hubitat and controller are on same network
  • Check firewall rules

"Device responded but doesn't appear to be an Oelo controller"

Possible causes:

  • IP address points to different device
  • Controller firmware version incompatible

Solutions:

  • Verify correct IP address
  • Test manually: curl http://{IP}/getController
  • Should return JSON array

Patterns not appearing in dropdown

  • Ensure patterns have been captured using Get Pattern command
  • Refresh your browser page - Changes only appear after refreshing the Hubitat page
  • Check device logs for any errors

Commands not working

⚠️ Most Common Issues

If commands like On, Off, or Apply Pattern are not working, check these in order:

  1. Controller IP Address not configured: Run Scan for Controller OR manually enter Controller IP Address in preferences, then save. Without this, the device cannot communicate with the controller.
  2. Pattern not captured: Make sure you've set a pattern in the Oelo Evolution app first, then run the Get Pattern command to capture it
  3. Refresh browser page: Refresh your browser page to see the pattern in preferences
  4. Pattern not selected: Select the pattern in the Pattern Selection dropdown
  5. Now try your commands again
  • Verify pattern is selected in Pattern Selection dropdown
  • Check device logs for error messages
  • Enable Debug Logging for detailed information
  • Verify controller IP and zone number are correct

Changes not showing in preferences

Solution: After capturing patterns, renaming patterns, deleting patterns, or changing any settings, you must refresh your browser page (F5 or Cmd+R) for the changes to appear in the preferences tab. The device works immediately, but the UI needs to be refreshed to display updates.

Device shows offline

  • Check controller IP address is correct
  • Verify network connectivity
  • Try Refresh command
  • Check Hubitat logs for connection errors

Requirements

  • Hubitat Elevation hub (firmware 2.1.9 or later)
  • Oelo Lights controller on local network
  • Controller IP address (can be manually entered or discovered via Scan for Controller)
